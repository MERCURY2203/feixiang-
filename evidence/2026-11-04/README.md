# 本機隔離重現資料包

對應 MERCURY2203/feixiang-booking 提交 75dbdf09dcabebc79baef412bc30578346d388fd。

解壓縮後，在此資料夾開啟終端，使用 Node.js 24 執行：

```sh
node audit.cjs
```

不需要 npm install，不連接微信或任何遠端服務。repo/ 是供重現用的文字程式快照，未包含圖片。測試透過 JavaScript VM 載入原始函數，替換資料庫與支付服務；部分案例直接呼叫內部函數以安排交錯執行順序。

輸出 REPRODUCED 及結束碼 0 表示 12 個錯誤案例被重現，並不表示程式沒有 bug。audit-results.json 會寫入本輪結果。隨機退款單號及日期隨執行時間變動。

此資料庫替身未完整實作雲端事務、重試、查詢上限、安全規則或平台行為。雲端呼叫可達性、真正的支付與並發結果仍須在微信測試環境驗證。

請配合檢查報告閱讀，勿將本資料包當成修復後的可部署專案。
